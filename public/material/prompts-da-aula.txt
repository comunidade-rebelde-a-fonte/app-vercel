TELEPROMPTER

Construa um app web de teleprompter que rode localmente.

Tecnologia: Vite + React + TypeScript. Sem servidor (backend), sem contas, sem telemetria e sem chamadas a APIs externas.

Toda a interface, os textos, os avisos e o README devem estar em português do Brasil.

Dados: os roteiros ficam no localStorage no formato {id, titulo, texto, atualizadoEm}. Entregue com um roteiro de exemplo, curto, sobre "como usar a IA no escritório contábil com contexto e revisão humana". Sem nuvem, sem sincronização, sem login.

Layout: duas telas em uma única página.
1) Biblioteca: listar roteiros, criar, renomear, excluir e editar o texto em uma caixa de texto simples, com salvamento automático ao sair do campo.
2) Tela de leitura: exibição em tela cheia do roteiro selecionado, rolando.

Requisitos da tela de leitura:
- Letra muito grande por padrão, com tamanho da fonte, altura da linha e largura do texto ajustáveis.
- Rolagem contínua e suave controlada por requestAnimationFrame, com velocidade em pixels por segundo (não use animação CSS).
- Controles: espaço liga e pausa; seta para cima e para baixo muda a velocidade; seta para a esquerda e para a direita volta ou avança o equivalente a 3 segundos de rolagem; R volta ao início; M liga e desliga o espelhamento horizontal; F liga e desliga a tela cheia; Esc sai.
- Uma linha-guia fixa de leitura, com posição vertical ajustável.
- O modo espelho aplica transform: scaleX(-1) somente na camada do texto; os controles continuam legíveis.
- Camada de câmera opcional: pré-visualização com getUserMedia atrás do texto, com opacidade ajustável. Se a permissão for negada, use fundo sólido e avise uma única vez, de forma discreta.
- Gravação opcional: MediaRecorder sobre o fluxo de câmera e microfone, salvando um arquivo .webm para download. Não tente gravar o texto junto com a imagem.
- Acompanhamento por voz opcional, atrás de um interruptor chamado "experimental": use a API SpeechRecognition do navegador com o idioma pt-BR, compare por aproximação as palavras reconhecidas com as próximas palavras do roteiro e ajuste a rolagem em direção à palavra encontrada. Se SpeechRecognition não existir no navegador, esconda o interruptor.

Guarde as configurações do usuário (velocidade, tamanho da fonte, espelho, opacidade, posição da linha-guia) no localStorage.

Fora do escopo: controle remoto por outro dispositivo, contas, compartilhamento de roteiros, legendas gravadas no vídeo, aplicativo de celular.

Estilo: CSS simples, fundo escuro, alto contraste, sem biblioteca de interface. Os controles somem sozinhos após 3 segundos sem mexer o mouse durante a leitura.

Entregue um README em português com: npm install, npm run dev, a lista completa de atalhos de teclado e um aviso de que câmera e microfone só funcionam em localhost ou HTTPS. Não precisa de arquivo .env, pois não há segredos.

Ao final, rode o app (npm run build para conferir que compila) e me diga exatamente o que foi feito, o que não ficou pronto e como abrir no navegador.

MANIPULADOR DE PDF

Construa uma versão pessoal e simples de manipulador de PDF em uma pasta vazia.

Tecnologia: Vite + React + TypeScript, com a biblioteca pdf-lib. Tudo roda no navegador: sem servidor, sem banco de dados, sem contas, sem telemetria e sem enviar nenhum arquivo para fora do computador. Não ofereça outras tecnologias.

Toda a interface, os avisos e o README devem estar em português do Brasil.

O que o app faz:
- Juntar vários PDFs em um só, na ordem que o usuário escolher (arrastar para reordenar).
- Dividir um PDF: por intervalo de páginas (por exemplo 1-3, 5, 8-10) ou uma página por arquivo.
- Reordenar e girar páginas, com miniaturas de visualização.
- Baixar o resultado como um novo arquivo. O arquivo original nunca é alterado nem sobrescrito.

Regras:
- Validar a entrada: aceitar apenas PDF, tratar nomes de arquivo com segurança e mostrar erro claro para arquivo corrompido ou protegido por senha.
- Avisar o usuário, antes de gerar, que PDFs com assinatura digital, formulários ou criptografia podem perder essas características ao serem juntados ou divididos.
- Mostrar um aviso fixo e visível: "Uso para tarefas simples. Não substitui ferramentas profissionais. Não use com documentos sigilosos sem conferir o resultado."
- Incluir estados claros de vazio, carregando, sucesso e erro com possibilidade de tentar de novo.
- Sem contas, sem cobrança, sem telemetria, sem análise de uso. Não guardar nenhum arquivo do usuário depois que a página for fechada.

Deliberadamente fora do escopo: compressão de PDF, OCR, marca d'água, redação de trechos, conversão de Word ou Excel para PDF, assinatura eletrônica de qualquer tipo, verificação de identidade e edição no nível do Acrobat.

Escreva testes enxutos para as funções de juntar e dividir e um teste de ponta a ponta do caminho feliz com PDFs de exemplo gerados pelo próprio teste.

Crie um README com instalação (npm install, npm run dev), como usar, como rodar os testes, onde ficam os dados (em lugar nenhum, tudo em memória) e as limitações.

Ao final, rode os testes e me liste os comandos exatos usados, o que funcionou e o que não ficou pronto.
